# Code of Conduct

## Our Pledge

We pledge to make participation in this project a harassment-free experience for everyone,
regardless of experience level, background, or identity. This is a learning community —
beginners are welcome and mistakes are part of learning.

## Standards

Examples of behavior that contributes to a positive environment:
- Constructive, specific feedback on PRs and issues
- Patience with learners asking "basic" questions
- Crediting original sources for datasets, diagrams, and code references

Examples of unacceptable behavior:
- Harassment, insults, or personal attacks
- Publishing others' private information
- Plagiarizing content without attribution

## Enforcement

Instances of abusive behavior may be reported to the repository maintainers via GitHub
Issues (marked confidential where possible) or direct contact. Maintainers will review and
respond to all reports.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
