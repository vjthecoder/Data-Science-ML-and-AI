## Session Format (per day)
1. **Warm-up (10 min):** Review previous day's exercise solutions
2. **Theory (20-30 min):** Walk through the notebook's Theory + Visual Explanation sections
   at all 3 levels
3. **Live coding (30-45 min):** Work through the Simple Example and Real-World Example cells
4. **Guided exercise (30 min):** Students attempt the Coding Exercise; instructor circulates
5. **Lab/Assignment (remaining time):** Independent or paired work
6. **Wrap-up (10 min):** Common Mistakes + Best Practices recap, preview next day

## Success Criteria
By the end of Week 1, students can:
- Write Python functions and classes with proper type hints
- Perform vectorized array operations with NumPy
- Clean, filter, group, and visualize tabular data with Pandas/Matplotlib/Seaborn
- Call a REST API, parse JSON, and query a SQL database from Python
