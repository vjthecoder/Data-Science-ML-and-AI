# Further Reading

Curated resources by week. Prefer primary sources (papers, official docs) over blog summaries.

## Week 1 — Python for Data Science
- Wes McKinney, *Python for Data Analysis* (the Pandas book, by its creator)
- NumPy and Pandas official user guides
- Real Python — tutorials on OOP, APIs, and file I/O
- *Effective Python* by Brett Slatkin — idiomatic Python patterns

## Week 2 — Machine Learning
- Aurélien Géron, *Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow*
- scikit-learn user guide (model selection, pipelines, metrics)
- XGBoost documentation and the original paper (Chen & Guestrin, 2016)
- Google's *Rules of Machine Learning* (practical ML engineering guidance)

## Week 3 — GenAI Foundations
- Vaswani et al., *Attention Is All You Need* (2017) — the Transformer paper
- Jay Alammar, *The Illustrated Transformer*
- Andrej Karpathy, *Let's build GPT* / nanoGPT (build a transformer from scratch)
- Anthropic docs — prompt engineering, tool use, structured outputs
- OpenAI & Google Gemini API references
- Model Context Protocol specification (modelcontextprotocol.io)
- Wei et al., *Chain-of-Thought Prompting* (2022)

## Week 4 — RAG
- Lewis et al., *Retrieval-Augmented Generation* (2020)
- LangChain and LlamaIndex documentation
- FAISS wiki (index types: Flat, IVF, HNSW) and the FAISS paper
- Chroma and pgvector docs
- Liu et al., *Lost in the Middle* (long-context retrieval limitations)
- RAGAS documentation (RAG evaluation)

## Week 5 — AI Automation
- n8n official documentation and the AI Agent node docs
- n8n workflow templates library
- WhatsApp Business Platform & webhook docs

## Week 6 — Deployment & LLMOps
- FastAPI, Streamlit, and Docker official documentation
- *The Twelve-Factor App* methodology (config, secrets, disposability)
- Cloud deployment docs: AWS App Runner/ECS, GCP Cloud Run, Render, Railway
- Chip Huyen, *Designing Machine Learning Systems* and *AI Engineering*
- Observability tools: LangSmith, Arize Phoenix, Weights & Biases
