# Diagrams

Architecture and concept diagrams referenced throughout the bootcamp, organized by week.

- `week01_python/` — Data flow diagrams (Pandas pipeline, API -> DataFrame)
- `week02_ml/` — ML workflow diagram (EDA -> Feature Eng -> Train -> Evaluate)
- `week03_genai/` — Transformer/attention diagrams, agent loop, MCP architecture
- `week04_rag/` — RAG pipeline diagram, chunking/embedding/retrieval flow
- `week05_n8n/` — n8n workflow architecture diagrams
- `week06_capstone/` — Capstone application architecture diagram

Diagrams are provided as Mermaid (`.md`) files for easy viewing/editing on GitHub.
