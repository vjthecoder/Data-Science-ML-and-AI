# Data Science, Machine Learning and Artificial Intelligence

Key notes and learnings in Data Science, Machine Learning, and AI. Primary language: Python.

## 🎓 AI Engineering Bootcamp

This repo hosts a complete, project-based curriculum:
**[AI Engineering Bootcamp: From Python to Production AI Systems](AI-Bootcamp/README.md)** —
6 weeks, from Python fundamentals to deploying production GenAI systems (RAG, agents,
automation, and a capstone AI Career Coach). **Status: v1.0.0 — all 6 weeks complete.**

| Week | Topic |
|------|-------|
| 1 | [Python for Data Science & AI](AI-Bootcamp/week01_python) |
| 2 | [Machine Learning Basics & ML Workflow](AI-Bootcamp/week02_ml) |
| 3 | [GenAI Foundations & LLM Working Procedure](AI-Bootcamp/week03_genai) |
| 4 | [RAG: Retrieval Augmented Generation](AI-Bootcamp/week04_rag) |
| 5 | [AI Automation with n8n](AI-Bootcamp/week05_n8n) |
| 6 | [Final Project, Deployment & GitHub Packaging](AI-Bootcamp/week06_capstone) |

Every concept is taught as: Theory → Visual Explanation → Simple Example → Real-World Example →
Coding Exercise → Assignment → Interview Questions → Industry Use Cases. Notebooks use
[Marimo](https://marimo.io); concept notebooks run offline (no paid API keys needed).

See the bootcamp [README](AI-Bootcamp/README.md), [CHANGELOG](CHANGELOG.md), and
[CONTRIBUTING](CONTRIBUTING.md) to get started.
